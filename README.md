# LuckyBox

광고 없이 사용할 랜덤 게임 사이트. 참가자 관리와 그룹별 사다리, 핀볼, 룰렛, 카드 뒤집기, 슬롯 머신을 제공합니다.

## 미리보기

Node.js 환경에서 `npm run dev`를 실행한 뒤 http://127.0.0.1:4173 에 접속합니다. 파일 수정 후 브라우저를 새로고침하면 반영됩니다. 외부 패키지 설치는 필요 없습니다.

## 구현 범위

- 최대 10개 그룹 생성·이름 변경, 그룹별 참가자 추가·삭제·이동 및 일괄 입력
- 전체 참가자 최대 50명, 중복 이름 제외, 기존 단일 명단은 자동으로 `1조`로 이전
- 현재 브라우저 localStorage에 그룹과 명단 저장
- 사다리 타기, 룰렛, 핀볼, 카드 뒤집기, 슬롯 머신 선택
- 반응형 화면 및 키보드 조작
- 게임 선택 시 별도의 큰 게임 화면으로 이동
- 각 게임에서 저장된 그룹을 하나 이상 선택해 순서대로 진행하고, 그룹 이름이 유지된 전체 결과판에서 결과 확인
- 사다리: 1~10개 그룹 구성, 무작위 조 편성, 개별 그룹 이동, 그룹별 결과 직접 입력
- 인원수만큼 금액, 꽝, 상품, 역할 등을 자유롭게 설정하고 각 참가자의 이름을 눌러 개별로 경로와 결과를 공개
- 확인한 참가자의 결과만 결과판에 표시하며 미확인 결과는 숨기고, 그룹별 결과를 복사할 수 있습니다.
- 사다리는 Web Crypto 기반 무작위 가로선과 독립적인 결과 위치 섞기를 사용하며, 입력한 모든 결과가 한 번씩 배정됩니다.
- 라운드 결과는 현재 페이지에서만 유지됩니다. 새로고침이나 페이지 이동 시 경고하며, 보관하려면 결과를 복사하세요.
- 핀볼: 에메랄드 가든, 네온 팩토리, 선셋 캐니언 3개 종합 코스
- 세 코스 모두 범퍼, 회전 날개, 경사로를 포함하며 색상과 장애물 배치가 다릅니다.
- 대기 게이트 없이 출발부터 결승선까지 이어지며 6 / 10 / 14구간의 코스 길이를 선택할 수 있습니다.
- 자동 추적 카메라, 개인 공 추적, 전체 코스 미니맵, 실시간 순위, 일시정지 및 1 / 2 / 4배속을 제공합니다.
- 핀볼은 고정 시간 간격의 중력·장애물 충돌 시뮬레이션으로 도착 순위를 결정합니다. 멈춘 공에는 가로 방향의 무작위 힘을 가하며 공끼리는 충돌하지 않습니다. 순위는 미리 정하지 않습니다. 배속은 물리 단계를 건너뛰지 않습니다. 백그라운드 탭에서는 진행을 멈춥니다.
- 룰렛: 동일한 크기의 참가자 칸, 5.2초 감속 연출, 연출 건너뛰기, 복수 당첨자 순차 추첨 및 당첨자 자동 제외
- 카드 뒤집기: 참가자별 이름 카드, 3D 뒤집기 연출, 개별 결과 공개, 미확인 결과 숨김 및 그룹별 결과 복사
- 슬롯 머신: 세 개의 이름 릴, 4.2초 회전 연출, 연출 건너뛰기, 복수 당첨자 순차 추첨 및 당첨자 자동 제외

## 파일

- `dist/index.html`: 화면 구성
- `dist/styles.css`: 스타일 및 반응형 레이아웃
- `dist/app.js`: 참가자 상태와 게임 선택
- `dist/theme.css`: 다크 테마
- `dist/game.html`, `dist/game.css`, `dist/game.mjs`: 전용 게임 화면과 그룹 진행
- `dist/ladder-engine.mjs`: 사다리 생성, 경로 계산, 조 편성
- `dist/pinball-engine.mjs`: 3개 맵, 공의 충돌 및 도착 순위 계산
- `dist/pinball-ui.mjs`, `dist/pinball.css`: 맵 선택, 레이스 화면, 카메라, 순위
- `dist/roulette-engine.mjs`, `dist/roulette-ui.mjs`, `dist/roulette.css`: 룰렛 추첨, 회전 연출, 당첨자 표시
- `dist/card-engine.mjs`, `dist/card-ui.mjs`, `dist/card.css`: 카드 결과 배정, 개별 공개, 뒤집기 연출
- `dist/slot-engine.mjs`, `dist/slot-ui.mjs`, `dist/slot.css`: 슬롯 당첨자 추첨, 이름 릴 연출, 당첨자 표시
- `server.mjs`: 로컬 미리보기 서버

검증: `npm run check`, `npm test` (사다리 경로, 핀볼 3개 코스 및 2~50명 완주, 게이트 제거, 룰렛·슬롯 중복 없는 연속 추첨, 카드 당첨 수와 중복 공개 방지)
